# AI Прораб — Агент технического заказчика для ремонта

> Проект для хакатона **HackAlem** (Астана, 23 сентября 2026).  
> Автономный агент, превращающий хаотичный запрос на ремонт в проверенные факты, перечень неизвестного, безопасный черновик WorkBrief и рекомендацию следующего шага с гарантией Human-in-the-Loop.

---

## 🎯 Концепция и границы продукта

В ремонте ранняя смета часто строится при неполных исходных данных. **AI Прораб не пытается угадать цену:** он фиксирует известное, показывает пробелы и формирует безопасный черновик задания для специалиста.

- **Показываем:** первичный разбор запроса, tool execution trace, policy guard, безопасный черновик WorkBrief, подтверждение человеком (Human Approval).
- **Не показываем:** финальную смету, подбор/отправку реальных подрядчиков, заказ стройматериалов, юридические заключения, персональные данные.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск тестов (Vitest)
```bash
npm test
```
*Проверяются все 7 инвариантов безопасности: извлечение сущностей с provenance, перехват запроса цены, изоляция пробелов, запрет автодопущений, блокировка внешних действий при approval, идемпотентность по ключу, честный demo-режим.*

### 3. Проверка линтера и типов
```bash
npm run lint
```

### 4. Сборка продакшн-версии
```bash
npm run build
npm start
```

### 5. Локальная разработка
```bash
npm run dev
```
Интерфейс доступен по адресу: [http://localhost:3000](http://localhost:3000).

## 🌟 Главный конкурсный сценарий

> **«Купил двухкомнатную квартиру в Астане, 58 м². Хочу современный ремонт, заехать через 4 месяца, бюджет пока не понимаю»**

На экране жюри за 10 секунд видит:
1. **Подтверждённые факты:** Астана, 2-комнатная квартира, 58 м² (из сообщения), срок 4 месяца, современный стиль ремонта.
2. **Критические неизвестные:** Исходное техническое состояние квартиры, бюджетный коридор, инженерные сети и стояки, доступ на объект.
3. **Ровно 3 умных вопроса:** с быстрыми вариантами ответа, которые фиксируются в черновике.
4. **Рекомендованный следующий шаг:** *«Инструментальный обмер специалистом»*.
5. **Safety Notice:** *«Финальная стоимость не формируется до инструментального обмера специалистом и согласованного WorkBrief — чтобы не обещать цифру, которую объект не подтвердил»*.
6. **Черновик WorkBrief & Human Approval:** статус `DRAFT_PENDING_APPROVAL`, подтверждение человеком фиксирует документ (`APPROVED_BY_HUMAN`), а внешние действия (тендер, подрядчики, закупка) остаются строго `LOCKED`.
7. **Tool Execution Trace:** скрытый в disclosure полный аудируемый след выполнения инструментов для жюри.

## ⚙️ Режимы работы (AI Engine Modes)

1. **Demo mode (по умолчанию):**  
   `engine_mode: deterministic`, бейдж: **«Demo mode · Rules + Safety Guard»**.  
   Работает полностью оффлайн без внешних API-ключей, стабильно и быстро.
2. **Hybrid mode (при наличии серверного ключа):**  
   Включается при `AGENT_ENGINE_MODE=hybrid` и наличии `OPENAI_API_KEY` в файле `.env`.  
   Серверный адаптер обращается к LLM только за структурированным JSON по Zod-схеме, пропуская результат через Policy Guard.
3. **Deterministic fallback:**  
   При таймауте (3.5 с), сетевом сбое или невалидном ответе внешней модели система автоматически переключается в безопасный fallback с бейджем **«AI недоступен — показан безопасный demo fallback»**.

Ключи хранятся **только на сервере** и никогда не передаются в браузерный бандл или Git.
